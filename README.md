## 📖 About

Visual Data is a front-end practice project that models the website of a data-driven company. It was built to practice designing a real-world, component-based UI with React, structuring a front-end codebase cleanly, and delivering a fully responsive experience across devices.

## ✨ Features

- Component-based architecture – pages are composed from reusable React components
- Responsive design – optimized for mobile, tablet, and desktop screens
- Client showcase slider – a smooth, touch-friendly carousel powered by Swiper.js
- Realistic company structure – multi-section layout that mirrors a real data analytics business
- Clean project organization – clear separation of files and responsibilities

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm (comes with Node.js)

### Installation

# Clone the repository
git clone https://github.com/MamadNematy/Visual-Data.git

# Navigate to the project directory
cd Visual-Data

# Install dependencies
npm install

# Start the development server
npm start
The app will be available at http://localhost:3000 (or the port shown in your terminal).
